# ECW Documentation Discussions

This public repository stores comments and feedback for the [ECW documentation site](https://docs.edgebench.io).

## How it works

- Each documentation page has its own GitHub Discussion.
- Readers sign in with GitHub before commenting.
- Comments are public and are moderated by the ECW maintainers.
- Documentation source remains in the private ECW documentation repository.

## Public-content rule

Do not post passwords, access tokens, customer information, private infrastructure details, or other confidential data. Use the private engineering channels for security issues and operational incidents.

## Moderation

Maintainers may answer, move, lock, hide, or remove comments. Use comments for documentation questions, corrections, and improvement suggestions.
